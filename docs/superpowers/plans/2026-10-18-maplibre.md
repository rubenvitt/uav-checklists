**Goal:** Die Einsatzkarte der Flugmappe läuft auf dem Kartensystem von Suchlage (MapLibre mit VersaTiles-Basiskarte) statt auf Leaflet/Geoman, mit gleichem Funktionsumfang.

**Architecture:** `EinsatzMap` wird eine MapLibre-Karte. Die gespeicherten Einsatzkarten (`MapData`, GeoJSON in `localStorage`) bleiben im selben Format und werden direkt als GeoJSON-Quelle gezeichnet. Gezeichnet wird wie in Suchlage über eigene Klicks (kein Zeichen-Framework). Das Bild für den PDF-Bericht kommt aus dem Canvas der Karte.

**Tech Stack:** React 19, TypeScript strict, Vite 8, `maplibre-gl` 6.13.0 (wie Suchlage), vite-plugin-pwa/Workbox, Tailwind 4.
